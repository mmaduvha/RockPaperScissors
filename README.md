Rock Paper Scissors:

A simple, well-structured console game built to demonstrate clean code and good programming practices.

Overview:

This project is a console-based version of the classic Rock, Paper, Scissors game. 
It is designed to show how to write  organised and maintainable code using object-oriented principles.

Features

Object-Oriented Design: The code separates game rules, players, and score tracking into different parts for better organisation.

Input Validation: The program checks user input carefully to prevent crashes when unexpected keys or words are entered.

Score Tracking: Keeps track of wins, losses, and ties during the game session.
